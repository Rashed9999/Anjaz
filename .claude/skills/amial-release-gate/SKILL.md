# بوابة إصدار أميال

## قاعدة القرار

لا يُدمج ولا يُنشر أي تغيير مالي أو أمني أو عابر للمنصات حتى تتوافر أدلة بوابته. حالة PR المغلق أو الأخضر وحدها ليست دليل نشر.

## البوابات

1. **النطاق**: تذكرة/مواصفة، أثر متوقع، وملفات متأثرة معلنة.
2. **المراجعة**: مراجعة مواصفة وقواعد المستودع، مع فصل المراجع عن منفذ التغيير في التغييرات الحساسة حيث أمكن.
3. **التحقق**: نجاح CI الرسمي، والاختبارات الجديدة، واختبارات الانحدار المناسبة.
4. **البيانات**: مراجعة الهجرة، النسخ الاحتياطي، قابلية الرجوع، وعدم وجود حذف أو تحويل غير قابل للعكس بلا موافقة صريحة.
5. **العقود**: اختبار تكامل/توافق عند تغير API أو الرسائل بين المنصات.
6. **الأمن**: لا أسرار، ولا توسيع صلاحيات غير مبرر، ولا تحذير Critical أو High غير مقبول بخطة معالجة موثقة.
7. **التشغيل**: متغيرات البيئة، التنبيه، المراقبة، وخطة الرجوع معروفة قبل التفعيل.

## قرار موثق

اكتب واحدًا فقط: `READY_TO_MERGE` أو `BLOCKED` أو `READY_FOR_CONTROLLED_ENABLEMENT`، مع الروابط والأدلة والمالك والخطوة التالية. لا تستخدم عبارة «تم» بدل القرار.

## دليل الاكتمال

يكون الإصدار جاهزًا فقط عندما يتطابق رأس PR المراجع مع رأس CI الناجح، وتكون البوابات المنطبقة مثبتة، ولا يوجد مانع مفتوح.
