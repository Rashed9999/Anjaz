# SMSGate — مزوّد الرسائل القصيرة (AMIAL-MESSAGING-003)

المحوّل: `01_backend/app/Services/Messaging/Providers/Sms/SmsGateProvider.php` (مفتاحه `sms_gate`، قناة `sms`، أولوية 10 — يُجرَّب أولًا ثم التالي عند فشله).
العقد: <https://github.com/capcom6/android-sms-gateway> ← `app/src/main/assets/api/swagger.json` (`POST /messages`، مصادقة Basic).

## كيف تعمل
الرسالة تخرج من **شريحة هاتف أندرويد** عليه تطبيق SMSGate. الخادم السحابي (`https://api.sms-gate.app/3rdparty/v1`) يضع الطلب في طابور الجهاز والجهاز يرسله.
- ردّ `202 Pending` = **دخل طابور الجهاز** وليس «وصل». المعرّف يُسجَّل في السجلّ (`message_id`) ويُستعلم عنه بالأمر أدناه.
- الرسالة تُسقَط من الطابور بعد `ttl` (الافتراضي 300 ثانية) حتى لا يصل رمز منتهٍ بعد ساعة من هاتف مطفأ.
- فشل SMSGate لا يُقفل التسجيل: السجلّ يجرّب المزوّد التالي (واتساب/غيره) ثم يعلن الفشل.

## الإعداد (لا أسرار في المستودع)
1. ثبّت التطبيق على الهاتف وفعّل «الخادم السحابي»؛ سيعرض اسم مستخدم وكلمة مرور.
2. لوحة الإدارة ← إعدادات ← الرسائل القصيرة ← `sms_gate`، واملأ:

| الحقل | المعنى | افتراضي |
|---|---|---|
| `username` / `password` | من التطبيق (كلمة المرور تُقنَّع في اللوحة) | — مطلوبان |
| `base_url` | **https فقط**؛ يُرفض `http` وعناوين IP الداخلية و`localhost` | `https://api.sms-gate.app/3rdparty/v1` |
| `device_id` | تثبيت جهاز بعينه (اختياري) | أي جهاز مسجَّل |
| `sim_number` | 1–3 (اختياري) | الشريحة الافتراضية |
| `ttl` | صلاحية الرسالة في الطابور بالثواني (30–3600) | 300 |
| `otp_template` | نص الرسالة؛ `#OTP#` يُستبدل بالرمز | `رمز التحقق: #OTP#` |

3. قبل التفعيل، افحص دون إرسال أي رسالة:

```bash
php artisan amial:sms-gate-check                      # الاتصال، المصادقة، عدد الأجهزة
php artisan amial:sms-gate-check --message-id=<ID>    # حالة رسالة أُرسلت
```

## ما لم يُبنَ بعد (مهام مفتوحة)
- **خطّاف التسليم** (`sms:delivered` / `sms:failed` عبر `POST /webhooks`): يلزم تحقق توقيع الطلب الوارد وجدول حالات؛ لم يُبنَ لأن توثيق التوقيع لم يُراجَع. حتى ذلك الحين الحالة بالاستعلام اليدوي.
- **حدّ الإرسال لكل شريحة** ومراقبة رصيد الشريحة وبطارية الهاتف: نقاط فشل مادّية خارج الخادم.
- **الرمز التجريبي الثابت `AMIAL_DEMO_OTP` لم يُمسّ**: تفعيل SMSGate لا يعطّله. إفراغه قرار منفصل بعد اختبار وصول حقيقي (انظر `PAY-GAP-04` في `plan.md`).
