# AMIAL-ACCOUNT-NUMBER-001 + AMIAL-CUSTOMER-WITHDRAW-001

## 1) رقم الحساب (8 أرقام + Luhn)
حلّ خصوصية: التحويل برقم الحساب بدل كشف الهاتف (مهم ثقافياً في اليمن).

| الملف | الدور |
|---|---|
| migration `..._add_account_number_to_users` | عمود فريد + توليد للحاليين |
| `AccountNumberService` | توليد/تحقّق Luhn/حلّ المستلِم (حساب أو هاتف) |
| `User` (boot creating) | توليد تلقائي للجدد |

- 8 خانات، آخرها خانة تحقّق **Luhn** (تمنع التحويل لحساب خاطئ بخطأ رقم).
- يُستبعد الأنماط القبيحة (11111111، 12345678).
- **المساحة الفعلية ~10 مليون** (7 بيانات + 1 تحقّق) — ضخمة لسوقك.
- التحويل بين العملاء: حساب **أو** هاتف (لم نمنع الهاتف). الوكيل: الاثنان.

## 2) السحب المبدوء من العميل
يلغي تكلفة SMS OTP، ويمنع حصاد الرموز عند الوكيل، ويثبت موافقة العميل.

**التدفّق:** العميل يطلب سحباً من جهازه → **يُحجز (المبلغ+الرسم) فوراً** →
عملية pending برقم عملية ومؤقّت انتهاء (config: 45 دقيقة) → الوكيل يُدخل رقم
العملية + معرّف العميل → يتحقق النظام (العملية حيّة، المعرّف يطابق، حدود الوكيل)
→ صرف المحجوز، إضافة للوكيل (المبلغ+العمولة)، ربح المنصّة → completed.

| الملف | الدور |
|---|---|
| `FinancialGuardService` | + `releaseHold` (فكّ) + `captureHold` (صرف نهائي) |
| migration `..._withdrawal_requests` | جدول الطلبات |
| `WithdrawalRequest` | النموذج |
| `CustomerWithdrawService` | request/cancel/execute/expireStale |
| `CustomerWithdrawController` | عميل (request/mine/cancel) + وكيل (lookup/execute) |

**حركة المال (مثال 10000، رسم 5%، عمولة وكيل 40%):**
- حجز العميل: 10500 (المبلغ+الرسم).
- التنفيذ: العميل −10500 (صرف المحجوز)، الوكيل +10200 (المبلغ+عمولة 200)، المنصّة +300.

**الحالات:** pending → completed / cancelled / expired (مع فكّ الحجز).

**الأمان:**
- الحجز الفوري يمنع الإنفاق المزدوج قبل وصول الوكيل.
- رقم العملية يُستهلك مرّة واحدة (lockForUpdate).
- مطابقة معرّف العميل (هاتف/حساب) دفاع في العمق.
- حدود الوكيل تُطبّق لحظة التنفيذ.
- بوابة دور الوكيل (type 1 أو AgentProfile) على lookup/execute.

**يتبقّى عليك:**
- شاشات Flutter (طلب السحب للعميل + شاشة تنفيذ الوكيل).
- أمر مجدول يستدعي `expireStale()` دورياً (Kernel schedule).
- قفل التطبيق بالبصمة (يحمي من إنشاء سحب على جهاز مسروق مفتوح).
