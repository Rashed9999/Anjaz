# CHANGELOG — AMIAL-FUEL-001 (الجولة الأولى)

**التاريخ:** 2026-05-31  
**الإصدار:** Backend v2.29 + Flutter v2.21

## القطاع المُضاف: محطات الوقود

أوّل **كاشير متخصّص** يميّز أميال باي عن باقي المحافظ اليمنية.

## النطاق المُنفَّذ (الجولة الأولى)

### Backend — 7 جداول

1. **`fuel_stations`** — محطة واحدة لكل تاجر.
2. **`fuel_pumps`** — مضخّات (يدوية/إلكترونية)، رقم فريد لكل محطة، عدّاد حالي.
3. **`fuel_products`** — أنواع الوقود مع السعر اللحظي.
4. **`fuel_pump_products`** — ربط المضخّة بأنواع الوقود التي تخدمها (مع رقم الفوّهة).
5. **`fuel_sales`** — عمليات البيع مع snapshot للسعر + قراءة العدّاد.
6. **`fuel_meter_readings`** — سجل قراءات للتدقيق.
7. **`fuel_company_accounts`** — حسابات الشركات للدفع الآجل.

### الخدمة (FuelStationService — ~440 سطر)
- `getOrCreateStation()` — محطة واحدة لكل تاجر مع إنشاء تلقائي.
- `addPump()` / `updatePump()` / `linkPumpToProducts()`.
- `addProduct()` / `updateProductPrice()` (يُستخدم بكثرة).
- **`recordSale()`** — الجوهر:
  - يحسب اللترات من المبلغ أو العكس حسب `sale_type`.
  - يدعم 3 طرق دفع: نقدي / أميال باي / بطاقة شركة.
  - للميكانيكية: يقرأ العدّاد قبل/بعد + يحدّث `current_meter_reading` تلقائياً.
  - **lockForUpdate** على حساب الشركة لمنع race condition.
  - يرفض إن الدَّيْن سيتجاوز `credit_limit`.
- `addCompanyAccount()` / `recordCompanyPayment()` — نظام حسابات الشركات.

### Controller — 16 endpoint
```
GET    /fuel/station                      → بيانات المحطة
POST   /fuel/station                      → إنشاء/تحديث

GET    /fuel/pumps                        → قائمة المضخّات
POST   /fuel/pumps                        → إضافة
PUT    /fuel/pumps/{id}                   → تحديث
POST   /fuel/pumps/{id}/link-products     → ربط أنواع الوقود

GET    /fuel/products                     → أنواع الوقود
POST   /fuel/products                     → إضافة
PUT    /fuel/products/{id}/price          → تحديث السعر

POST   /fuel/sales                        → الجوهر (rate-limit 300/دقيقة)
GET    /fuel/sales                        → السجل (فلاتر)
GET    /fuel/sales/{ulid}                 → تفاصيل
GET    /fuel/dashboard                    → إحصائيات اليوم

GET    /fuel/companies                    → قائمة
POST   /fuel/companies                    → إضافة
POST   /fuel/companies/{id}/payment       → سداد
```

### اختبارات — 13 اختباراً
- تفرّد المحطة لكل تاجر.
- تفرّد رقم المضخّة في المحطة.
- بيع بالمبلغ → يحسب اللترات (5000 ÷ 500 = 10 لتر).
- بيع باللتر → يحسب الإجمالي (20 × 500 = 10000 ر.ي).
- مضخّة يدوية → تحديث العدّاد تلقائياً.
- قراءة بعد < قبل → رفض.
- بيع بطاقة شركة → يزيد الدَّيْن.
- بيع تجاوز credit_limit → رفض.
- سداد ينقص الدَّيْن.
- مضخّة من تاجر آخر → رفض.

### Flutter — 3 شاشات رئيسية

1. **`FuelStationDashboardScreen`** — لوحة محطة الوقود (entry point):
   - بطاقة المحطة (الاسم + المدينة).
   - **إحصائيات اليوم**: الإجمالي + اللترات + عدد العمليات + توزيع حسب طريقة الدفع.
   - زر "بيع جديد" بارز + روابط للإعدادات والسجل.
   - Pull-to-refresh.

2. **`FuelSaleScreen`** — شاشة البيع (الجوهر، ~570 سطر):
   - اختيار المضخّة من شريط أفقي.
   - اختيار نوع الوقود من Chips ملوّنة (مع السعر).
   - زرّان: "بالمبلغ" / "باللتر".
   - حقل إدخال كبير مع **حساب لحظي** للقيمة الأخرى (مبلغ ↔ لتر).
   - للميكانيكية: مربّع قراءة العدّاد مع القيمة المتوقّعة.
   - حقول: لوحة السيارة + اسم السائق (اختياري).
   - 3 أزرار طريقة دفع (نقد/أميال باي/بطاقة شركة).
   - شركات: Dropdown مع الدَّيْن الحالي لكل شركة.
   - بطاقة ملخّص (الإجمالي + اللترات).
   - شاشة نجاح بـ Dialog.

3. **`FuelSettingsScreen`** — إعدادات المحطة (TabBar بـ 3 تابات):
   - **تاب 1:** قائمة المضخّات + إضافة (نوع + رقم + قراءة ابتدائية للميكانيكية) + تفعيل/تعطيل.
   - **تاب 2:** أنواع الوقود + الأسعار + تحديث السعر بنقرة.
   - **تاب 3:** بيانات المحطة (الاسم، الرخصة، المدينة، العنوان).

### نقطة الوصول
- بطاقة "محطة وقود" في **"خدماتي"** للتجّار.

## ما لم يُبنَ في هذه الجولة (للجولات القادمة)

1. **شاشات الشركات** (قائمة + كشف حساب + سداد) — Backend جاهز، Flutter ينقصها.
2. **شاشة سجل المبيعات** (Backend جاهز).
3. **بطاقات الشركة** (Cards): جدول مستقل، حدود يومية/شهرية.
4. **النوبات (Shifts)**: فتح/إغلاق نوبة + ملخّص نقدي.
5. **PDF إيصال بيع وقود** متخصّص.
6. **تقارير**: يومية/أسبوعية/شهرية.
7. **التكامل مع المضخّات الإلكترونية** الحقيقية (API integration).

## ملاحظات صدق

- **فحصي بنيوي فقط** (Node). لم أشغّل أيّ اختبار.
- **شاشة البيع جوهرية** لكنها للتجار/موظفي المحطة فقط (لا تظهر لعميل عادي).
- **سعر الوقت اللحظي** يُحفظ snapshot في `fuel_sales.price_per_liter` لمنع تغيّره أثر اًرجعياً.
- **العدّاد يُحدَّث تلقائياً** عند بيع ميكانيكي ناجح.
