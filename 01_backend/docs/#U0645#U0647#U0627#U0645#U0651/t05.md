# أميال باي — مهمة احترافية شاملة لتدقيق وإصلاح وإغلاق قطاع مكافحة غسل الأموال
## AML / CFT / Sanctions / PEP / Transaction Monitoring / Investigations / Regulatory Reporting

> هذه المهمة تخص شاشة واحدة متعددة التبويبات: **مكافحة غسل الأموال**.
>
> التبويبات الظاهرة: المؤشرات، العمليات المعلقة، العمليات الكبيرة، التقسيم، التنبيهات، التحقيقات، البلاغات التنظيمية، تقييم العمليات، القواعد، إضافة إلى العقوبات وPEP وقوائم المراقبة في طبقة الفحص.
>
> المطلوب ليس تجميل الشاشة؛ المطلوب تحويل AML إلى منظومة رقابية حقيقية قابلة للإثبات والتشغيل والمراجعة.

# 3) حالة "لا قواعد" = Critical Health

إذا `aml_rules_count = 0` اعرض أعلى الشاشة:

**CRITICAL — لا توجد قواعد AML فعالة؛ مراقبة المعاملات غير مفعلة.**

لا تعرض أصفارًا خضراء توحي بأن الفحص تم ولم يجد شيئًا.

# 4) منع Fail-Open الصامت

المحرك الحالي يسمح عمليًا بمسارين خطيرين:
1. لا قواعد → Allow.
2. Rule ترمي Exception → Log + Continue.

أنشئ Rule Criticality:
- legal/policy hard rule
- sanctions
- behavioral
- advisory

سياسة الفشل:

## Behavioral
يمكن degraded/flag/hold حسب policy.

## Hard policy / sanctions
لا يتحول الخطأ بصمت إلى Allow.

اعتمد Failure Policy موثقة:
- HOLD + degraded alert
- أو deny حسب السياسة

والشرط:

`critical AML evaluation failure silently allows transaction = 0`

# 10) CTR الحالي يحتاج مراجعة قانونية

الكود يتعامل مع `CTR` كأن كل عملية فوق حد ثابت يجب الإبلاغ عنها حتمًا.

هذا **ليس التزام FATF عالميًا بذاته**.

FATF يضع معيارًا للإبلاغ عن العمليات المشبوهة، أما threshold/currency reports فتتبع التشريع المحلي.

اليمن لديه:
- قانون مكافحة غسل الأموال وتمويل الإرهاب رقم 1 لسنة 2010
- تعديلات رقم 17 لسنة 2013
- وحدة جمع المعلومات المالية اليمنية

لذلك لا تعتمد اسم `CTR` أو حد `2,000,000` كواجب قانوني نهائي حتى يثبت Legal/Compliance المرجع المحلي الساري.

أنشئ:

`regulatory_reporting_policy`
- jurisdiction
- authority
- report type
- threshold إن وجد
- currency
- legal reference
- effective date
- owner

# 75) التوجيه النهائي

لا تحوّل المهمة إلى:
- بطاقات أجمل
- ألوان
- أصفار
- جدول Rules

الهدف:

`Every eligible transaction screened`
→ `Every decision persisted`
→ `Every alert explainable`
→ `Every case owned`
→ `Every action real`
→ `Every report provable`
→ `Every sanctions/PEP source fresh`
→ `Every critical change audited`

إذا الشاشة تقول "0" لأن النظام لم يفحص أصلًا، فهذا ليس نجاحًا.

إذا Rule موجودة في المستودع لكنها غير موجودة في الإنتاج، فهي غير موجودة فعليًا.

إذا النظام يقول "تم قبول المعاملة" ولم يتحرك ريال، فالنص خاطئ.

إذا الكود يدعي التزامًا قانونيًا بلا مرجع محلي مثبت، فالقطاع غير مغلق.
