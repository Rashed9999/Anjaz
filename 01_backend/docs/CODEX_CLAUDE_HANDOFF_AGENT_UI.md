# تسليم Claude Code — تكامل واجهة تشغيل الوكيل

## الحالة

هذه رقعة WIP أُعدت فوق `f572574` ولا يجوز وسمها مكتملة قبل الفحص في بيئة
تحتوي PHP وMariaDB وChromium وFlutter.

## ما تغيّر

- لوحة المدير صارت تبدأ بملخص تشغيلي وبطاقات متابعة قابلة للضغط، مع تجميع
  التبويبات الثانوية تحت «المزيد» لتقليل الفوضى على الهاتف.
- طلبات الموظفين وإدارة بلاغات الطوارئ تستعمل نوافذ Bootstrap داخل المشروع؛
  لم يعد القرار يعتمد على `prompt` أو `alert` الخامّين.
- أضيفت قراءة بلاغات الطوارئ وقرار المدير عليها؛ الصراف مرفوض خادمياً، وكل
  قرار مسجل في `AuditService`.
- `agent.overview` يحصر الفروع ومحفظة الشركة الأم حسب دور الداخل، ويضيف
  `attention` و`variance_total` مع بقاء حقول العجز والفائض القديمة.

## ضوابط مُتعمدة

- محدد محاولات دخول الوكيل (`RateLimiter`) **بقي**؛ الالتزام المصدر كان
  يحذفه، ولم يُنقل ذلك.
- تنسيق المبالغ في JavaScript بقي مبنياً على السلاسل، لا `Number`؛ لا حساب
  مالي داخل الواجهة.
- العجز والفائض منفصلان؛ `variance_total` مؤشر عرض إضافي فقط.
- لا تغيير لقاعدة البيانات أو Flutter أو المحفظة أو التسوية.

## المطلوب من Claude Code

1. شغّل `bash scripts/verify.sh` كاملاً. لا تكتفِ بـ `--fast`.
2. شغّل الاختبارات المركزة:

   ```bash
   php artisan test --filter=AgentPortalContractTest
   php artisan test --filter=AgentTellerWorkspaceTest
   ```

3. اختبر دخول الوكيل بست محاولات خاطئة وتأكد أن السادسة محجوبة، ثم دخول
   صحيح وتأكد من مسح العداد.
4. اختبر بثلاثة أدوار: `head_office` و`branch_manager` و`teller`:
   - مدير الفرع لا يرى محفظة الشركة الأم ولا فروعاً خارج نطاقه.
   - الصراف لا يرى «المتابعة» أو زر معالجة الطوارئ، وطلب API يرد بالرفض.
   - المدير يستطيع استلام البلاغ ثم إغلاقه بملاحظة من 10 أحرف على الأقل،
     ويتحقق سجل التدقيق.
5. في المتصفح اضغط: بطاقات المتابعة، «راجع المتابعة»، الموافقة والرفض،
   تحديث الطوارئ، وحفظ القرار؛ تحقق من حالة التحميل والفشل والنجاح.
6. بعد نجاح كل ما سبق، حدّث هذه الوثيقة بالنتائج فقط ثم انشرها. لا تعِد
   إدخال إزالة `RateLimiter` أو تحويل المبالغ إلى `Number`.

## الظهور

بوابة شركات الصرافة ← دخول مدير الشركة/مدير الفرع ← «الرئيسية» و«المتابعة»؛
الصراف يبقى في «الشباك» و«تقرير اليوم» فقط.
