# خريطة أميال باي

من جذر المستودع، مع Node 22.12 أو أحدث وGit وBash:

```sh
cd tools/project-map
npm ci
npm run build
```

افتح `floorplan/overview.html` من جذر المستودع. تعرض البطاقات مكوّنات المشروع بالعربية وتفتح الخريطة التفاعلية. أعد أمر البناء لتحديثها بعد تعديل الشيفرة. الخريطة خاصة بفريق التطوير وتُولّد محليًا.

يجلب البناء إصدار Floorplan المثبت في build.sh. بعد أول بناء يتاح أيضًا كمهارة محلية داخل المشروع عبر `.agents/skills/floorplan`. البطاقات من سجل shadcn/ui الرسمي (new-york-v4/card)، وتُبنى إلى HTML ثابت دون تحميل React في المتصفح.
